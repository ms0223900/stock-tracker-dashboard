# Design Stock Dashboard

## Instructions

1. Start from the MVP: stock symbol input, target price input, quote result, watchlist status, Telegram alert.
2. Keep the first version focused on one Taiwan stock symbol in full `.TW` format.
3. Use the `watchlist` table as the main data model.
4. Treat line chart, 60-second polling, delete, background checks, and historical prices as optional or later-phase features unless requested.
5. Describe acceptance criteria as observable user actions and expected outcomes.

## Output Checklist

- Problem and user goal are clear.
- Inputs and validation rules are explicit.
- UI regions are listed.
- Data fields and notification state are covered.
- Out-of-scope items remain out of scope.
