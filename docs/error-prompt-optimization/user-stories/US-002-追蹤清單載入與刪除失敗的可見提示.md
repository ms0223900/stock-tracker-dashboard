### US-002：追蹤清單載入與刪除失敗的可見提示

**作為** 使用者  
**我想要** 在無法從資料庫讀取追蹤清單或刪除項目失敗時，在畫面上看到明確提示  
**以便** 我知道不是「清單為空」而是發生錯誤，並可稍後重試

**輸入格式**：
- `useWatchlist` 內 `fetchWatchlist`：目前失敗時僅 `console.error` 並回傳 `null`，不更新 UI 錯誤狀態
- `handleDelete`：目前失敗時僅 `console.error`，使用者無法得知刪除是否成功
- `HomePage` 頂部 `ErrorBanner` 僅綁定 `queryError ?? saveError`，未涵蓋清單載入／刪除

**輸出格式**：
- 可選狀態：`watchlistError`、`deleteError`（或統一的 `watchlistActionError`）等，型別為 `string | null`
- 錯誤時在 `WatchlistCard` 區塊內或頂部 banner 顯示繁中訊息（與 US-001 常數一致）；成功重試後清除
- 載入失敗時與「尚無追蹤項目」空狀態在視覺／文案上可區分

**驗收條件**：
- [ ] 模擬 `select` 失敗時，使用者可看到錯誤提示，且不等同於空清單預設文案
- [ ] 模擬 `delete` 失敗時，使用者可看到錯誤提示；不僅僅依賴開發者工具 console
- [ ] 錯誤提示載明可依賴之行為（例如重新整理頁面、稍後再試），文案與 US-001 單一來源對齊
- [ ] 不產生空 `catch`；錯誤路徑須可追蹤（可 `console.error` 附帶 context，但須搭配 UI 提示）

**依賴關係**：
- **US-001**（建議先定義共用錯誤文案映射，再接到本 US 的 Supabase 分支）

**優先級**：P1  
**相關功能**：spec §6 追蹤清單區、§11 Supabase 錯誤提示、`hooks/useWatchlist.ts`
