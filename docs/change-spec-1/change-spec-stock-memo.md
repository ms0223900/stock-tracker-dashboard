# Change Spec：新增追蹤股票備註欄位

## 1. 我要改什麼？

在追蹤項目上新增一個選填的「備註」欄位，讓使用者記錄追蹤原因。

## 2. 這個改動會影響哪些地方？

- 資料庫欄位
- 新增追蹤項目的表單
- 追蹤清單顯示畫面

## 3. 怎樣算是改完了？

- [ ] 使用者新增追蹤項目時，可以填寫備註。
- [ ] 儲存後，追蹤清單可以看到備註文字。
- [ ] 備註留空時，既有功能不受影響。
- [ ] 通知邏輯與股價抓取仍然正常。

## 4. 這次不動什麼？

- 通知邏輯不動。
- 股價抓取不動。
- 目標價驗收條件不動。
- 除了顯示備註所需調整，不重構既有追蹤清單。

## 5. 要同步更新的文件

- [ ] 在 spec.md 或 User Story 中補上備註欄位與驗收標準。
