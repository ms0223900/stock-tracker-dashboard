### US-001：擴充股價資料介面與前收盤價提取

**作為** 前端開發者
**我想要** 從 Yahoo Finance API 回傳中提取 `previousClose`，並在 `StockPrice` 介面中提供 `change` 與 `changePercent` 欄位
**以便** 後續 UI（折線圖、漲跌顯示）有正確的資料可以判斷漲跌方向。

**輸入格式**：
- Yahoo Finance API 回傳的 raw JSON（chart API 的 `meta.previousClose` 欄位）
- 現有的 `StockPrice` interface（`lib/yahoo-finance.ts`）

**輸出格式**：
- 擴充後的 `StockPrice` interface，包含：
  - `previousClose: number | null`
  - `change: number | null`
  - `changePercent: number | null`
- `fetchStockPriceRaw()` 函數更新：
  - 從 `meta.previousClose` 讀取值
  - 計算 `change = currentPrice - previousClose`
  - 計算 `changePercent = (change / previousClose) * 100`
  - 若 `previousClose` 為 `null/undefined`，則 `change` 與 `changePercent` 也為 `null`

**驗收條件**：
- [ ] `StockPrice` interface 包含 `previousClose`、`change`、`changePercent` 三個新欄位
- [ ] `fetchStockPriceRaw()` 正確從 `meta.previousClose` 提取資料
- [ ] 當 `previousClose` 存在時，正確計算漲跌金額與百分比
- [ ] 當 `previousClose` 為 `null/undefined` 時，`change` 與 `changePercent` 為 `null`，不拋出錯誤
- [ ] `fetchStockPriceServer()`（server-side）不受影響，仍正常運作
- [ ] `check-prices/route.ts` 的通知邏輯不受影響，仍正常運作
