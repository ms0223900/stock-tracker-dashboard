### US-005：折線圖顯示前收盤價參考線（Nice-to-have）

**作為** 投資者
**我想要** 在折線圖中看到一條標示「前一日收盤價」的水平虛線
**以便** 我可以直觀對照今天盤中價格與昨收價的差距。

**輸入格式**：
- 已擴充的 `StockPrice` 物件（含 `previousClose`）
- 現有 Recharts `<LineChart>` 元件

**輸出格式**：
- 在折線圖中新增 `<ReferenceLine>` 元件：
  - `y` 值為 `previousClose`
  - 樣式為灰色虛線（`stroke="#71717a"`, `strokeDasharray="4 4"`）
  - 標籤顯示 "昨收 $X,XXX.XX"（使用 `formatPrice` 格式化）
- 若 `previousClose` 為 `null`，不顯示參考線

**驗收條件**：
- [ ] 折線圖中顯示一條灰色水平虛線，位置對應 `previousClose` 數值
- [ ] 虛線旁有文字標籤顯示昨收價格
- [ ] `previousClose` 為 `null` 時不顯示參考線
- [ ] 參考線不影響現有 tooltip、坐標軸的互動行為

**整體結論**：PASS ✅

> 所有驗收條件均已通過。
