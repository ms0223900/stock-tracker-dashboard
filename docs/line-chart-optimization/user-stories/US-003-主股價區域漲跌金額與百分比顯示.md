### US-003：主股價區域漲跌金額與百分比顯示

**作為** 投資者
**我想要** 在目前股價旁邊看到「今日漲跌金額」與「漲跌幅百分比」，並用紅綠色標示
**以便** 我可以快速了解今天股價相較於昨收的具體變動幅度。

**輸入格式**：
- 已擴充的 `StockPrice` 物件（含 `previousClose`、`change`、`changePercent`）

**輸出格式**：
- 主價格顯示區域（目前 `app/page.tsx` line 285-287）更新為：
  - 大號字體顯示 `currentPrice`
  - 旁邊顯示漲跌標示：
    - 上漲：`+$X.XX (+X.XX%)`，文字顏色為綠色
    - 下跌：`-$X.XX (-X.XX%)`，文字顏色為紅色
    - `previousClose` 為 `null`：只顯示股價，不顯示漲跌資訊，文字維持白色/灰色
- 顏色建議：綠色 `text-emerald-400` / 紅色 `text-red-400` / 灰色 `text-zinc-400`

**驗收條件**：
- [ ] 上漲時顯示 `+$X.XX (+X.XX%)`，文字為綠色
- [ ] 下跌時顯示 `-$X.XX (-X.XX%)`，文字為紅色
- [ ] 平盤（`change === 0`）時顯示 `$0.00 (0.00%)`，文字為灰色或綠色
- [ ] `previousClose` 為 `null` 時不顯示漲跌區塊，只顯示股價
- [ ] 漲跌金額與百分比數值正確（與 Yahoo Finance 計算一致）
- [ ] 漲跌資訊在 auto-poll 更新時也正確更新
