### US-002：折線圖依前收盤價動態顯示紅綠色

**作為** 投資者
**我想要** 折線圖的線條顏色根據當前股價與前一日收盤價的關係，自動顯示綠色（漲）或紅色（跌）
**以便** 我可以一眼判斷今日股價走勢方向。

**輸入格式**：
- 已擴充的 `StockPrice` 物件（含 `previousClose`、`change`、`changePercent`）
- 現有折線圖 `<Line>` 元件（`app/page.tsx`）

**輸出格式**：
- 折線圖的 `<Line stroke>` 屬性根據以下規則動態計算：
  - `currentPrice >= previousClose` → 綠色（`#22c55e`）
  - `currentPrice < previousClose` → 紅色（`#ef4444`）
  - `previousClose` 為 `null` → 灰色（`#a1a1aa`）

**驗收條件**：
- [ ] 當 `currentPrice > previousClose` 時，折線為綠色
- [ ] 當 `currentPrice < previousClose` 時，折線為紅色
- [ ] 當 `currentPrice === previousClose`（平盤）時，折線為綠色
- [ ] 當 `previousClose` 為 `null`（如 IPO 首日）時，折線為灰色
- [ ] 當 `chartData` 為空陣列時，折線圖不顯示，不報錯（維持現有邏輯）
- [ ] 首次載入尚未取得資料時，不出現色塊閃爍（FOUC）
