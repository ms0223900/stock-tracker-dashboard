### US-004：自選股表格價格漲跌顏色

**作為** 投資者
**我想要** 在自選股表格中看到每檔股票的 `last_price` 以紅綠色標示漲跌
**以便** 在列表中快速辨識哪些股票今天上漲、哪些下跌。

**輸入格式**：
- 自選股清單（`watchlist` state，`app/page.tsx`），每筆目前僅含 `last_price`
- 需要擴充 watchlist state，讓每筆也暫存 `previousClose` / `change` / `changePercent`
- 或：讓 watchlist auto-poll 更新時連同完整的 `StockPrice` 資訊一起更新 state

**輸出格式**：
- 自選股表格（`<table>`）中的 `last_price` 欄位：
  - 上漲（`last_price >= previousClose`）：文字顏色為綠色
  - 下跌（`last_price < previousClose`）：文字顏色為紅色
  - 無 `previousClose` 資料：維持現有白色/灰色

**驗收條件**：
- [ ] 若某一自選股已被查詢且有 `previousClose`，其 `last_price` 顯示紅綠漲跌顏色
- [ ] 若某一自選股尚未被查詢（無 `previousClose`），維持中性顏色
- [ ] auto-poll（每 60 秒）更新時，price 與顏色同步更新
- [ ] 不影響「已通知」「等待中」「刪除」等其他欄位的顯示

**依賴關係**：
- US-001（`StockPrice` 介面擴充與資料提取）
- 可與 US-002、US-003 平行實作

**優先級**：P1
**相關功能**：折線圖漲跌顯示優化
