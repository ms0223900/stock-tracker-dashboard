### US-010：套用設計系統主題配色與字體

**作為** 使用者
**我想要** 看板採用統一的淺色主題與專業字體
**以便** 獲得符合台灣金融市場風格的清晰閱讀體驗

**輸入格式**：
- `DESIGN.md` 定義的完整色彩系統（surface、primary、secondary、tertiary、error、inverse 等）
- `DESIGN.md` 定義的 Typography 系統（Inter 字體、display-lg / headline-md / title-sm / body-md / body-sm / label-caps / data-mono）
- `DESIGN.md` 定義的 spacing 系統（8px base、xs/sm/md/lg/xl）與 rounded 系統（0.25rem~1.5rem）
- 現有程式碼中的 Tailwind 深色主題 classes（bg-zinc-950、bg-zinc-900、text-white、text-emerald-400、text-red-400 等）

**輸出格式**：
- `layout.tsx`：引入 Inter 字體（Google Fonts）與 Material Symbols 圖示字體；`<body>` 背景改為 `bg-surface`、文字改為 `text-on-surface`
- `globals.css`：以 `@theme` 定義完整設計系統 tokens（colors、fontFamily、fontSize、spacing、borderRadius）
- `page.tsx` 及其他受影響檔案中的所有色票從暗色主題（zinc/emerald）替換為淺色設計系統對應 token
- 漲跌顏色從 Western 慣例（green=漲、red=跌）切換為 TWSE 台股慣例（red=漲 #EB0000、green=跌 #008A3B），影響走勢圖線條顏色與所有價格數字顏色

**驗收條件**：
- [ ] `<html>` 引入 Inter 字體且為 sans-serif 主字體
- [ ] Material Symbols 字體已載入，可正常顯示 icon
- [ ] 頁面背景為淺色（`#f3faff`），不再是深色
- [ ] 所有文字顏色對應到設計系統的 `on-surface` / `on-surface-variant` / `outline`，不再使用白色
- [ ] 主要按鈕使用 `primary` 藍色（#1976D2）
- [ ] 卡片與容器使用 `surface-container-low` / `surface-container-lowest` 搭配 `outline-variant` 邊框
- [ ] 漲價顯示為紅色系（`#EB0000` 或 `#dc2626`），跌價顯示為綠色系（`#008A3B` 或 `#16a34a`）
- [ ] 股價數字使用 `font-data-mono` 確保等寬數字對齊
- [ ] spacing 與 rounded 符合 8px 基數設計系統（卡片 radius 0.5rem、間距 16px/24px 等）
- [ ] 所有既有功能仍正常運作（查詢、顯示、儲存追蹤、刪除）

**依賴關係**：
- 無（基礎樣式變更，所有後續 UI 調整皆依賴此 US）

**優先級**：P0
**相關功能**：設計系統基礎建設
