### US-015：新增新聞橫幅與行動版底部導覽列

**作為** 行動裝置使用者与一般使用者
**我想要** 在儀表板看到新聞橫幅與行動版底部導覽列
**以便** 在手機上也能方便切換功能頁面，並獲取市場洞察資訊

**輸入格式**：
- 設計樣本 `code.html` 的「Institutional Insights」新聞橫幅區塊（漸層 overlay + 標題 + 說明 + 按鈕）
- 設計樣本 `code.html` 的 Mobile Bottom Navigation（HOME / WATCH / STATS / ALERTS 四個頁籤）
- 現有版面在 bento grid 最下方的剩餘空間

**輸出格式**：
- **新聞橫幅**（`col-span-12`，高度 `h-64`）：
  - 全寬圖片或 gradient 背景
  - 左側漸層 overlay（藍色半透明）
  - 標題「Institutional Insights」（白色大標）
  - 說明文字（白色半透明）
  - READ REPORT 按鈕（白色填充，藍色文字）
  - `rounded-xl` + `border` + `shadow-sm`
- **行動版底部導覽列**（`md:hidden`）：
  - 固定在底部（`fixed bottom-0`）
  - 四個導覽項目：HOME、WATCH、STATS、ALERTS
  - 每個項目含 Material Symbols icon + 文字標籤
  - HOME 為 active 狀態（藍色），其餘為次要色
  - 白色背景 + 上方邊框
- 確認主要內容不被底部導覽列遮擋（適當 padding-bottom）

**驗收條件**：
- [ ] 新聞橫幅顯示在 watchlist 下方，佔滿 12 欄
- [ ] 橫幅有漸層 overlay，左側文字清晰可讀
- [ ] 標題「Institutional Insights」使用白色大標
- [ ] READ REPORT 按鈕為白色背景藍色文字，hover 有效果
- [ ] 行動版（<768px）底部顯示導覽列
- [ ] 底部導覽列固定於畫面底部
- [ ] 四個導覽項目皆有 icon 與文字標籤
- [ ] HOME 項目為 active 狀態（藍色系）
- [ ] 頁面底部有足夠 padding 避免內容被導覽列遮擋
- [ ] 桌面版（≥768px）底部導覽列隱藏
- [ ] 所有既有功能不受影響

**依賴關係**：
- US-010（設計系統主題）
- US-011（版面結構）
- US-014（watchlist 完成後方在其下方加入橫幅）

**優先級**：P1
**相關功能**：新聞資訊與行動版體驗
