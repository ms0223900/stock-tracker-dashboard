### US-014：重新設計追蹤清單為卡片式佈局

**作為** 使用者
**我想要** 追蹤清單從表格改為卡片式呈現並附帶走勢圖
**以便** 更直觀地比較各股票的最新狀態與價格趨勢

**輸入格式**：
- 現有 `page.tsx` 的 `watchlist`、`watchlistLoading`、`handleDelete`、`deletingId` 狀態與邏輯（功能不變）
- 設計樣本 `code.html` 的「Active Watchlist」卡片區塊（每張卡片含 ticker、公司名、sparkline、目標價、當前價、狀態徽章、刪除按鈕）
- `StockPrice` 型別的 `previousClose` 欄位用於判斷漲跌色

**輸出格式**：
- **Watchlist 區塊標題列**：
  - 標題「Active Watchlist」
  - 右側 EXPORT CSV 按鈕（含 download icon，功能可暫為 placeholder）
- **卡片網格**（`md:grid-cols-2`）：
  - 每張卡片包含：
    - 股票代號（藍色）+ 公司簡稱
    - 刪除按鈕（紅色，hover 效果）
    - Sparkline SVG 走勢圖（高度 `h-12`，2px stroke，紅漲綠跌）
    - 目標價（TARGET）與當前價（CURRENT）左右排列
    - 當前價旁附狀態徽章：「Waiting」（藍色）或「Triggered」（綠色）
    - 當前價顏色依 TWSE 紅漲綠跌顯示
- 空白狀態：「尚未加入任何追蹤項目」訊息保留但樣式更新
- 載入中狀態保留但樣式更新

**驗收條件**：
- [ ] 標題顯示「Active Watchlist」而非「追蹤清單」
- [ ] EXPORT CSV 按鈕存在於標題列右側
- [ ] 追蹤項目以 2 欄卡片網格顯示（md 以上）
- [ ] 每張卡片顯示股票代號（藍色）與公司簡稱
- [ ] 每張卡片含 sparkline SVG 走勢圖
- [ ] sparkline 顏色紅漲綠跌（對比 `previousClose`）
- [ ] 每張卡片顯示 TARGET 目標價與 CURRENT 當前價
- [ ] 當前價旁有狀態徽章：尚未觸發顯示「Waiting」（藍色），已觸發顯示「Triggered」（綠色）
- [ ] 當前價顏色依 TWSE 慣例（高於昨收紅色、低於昨收綠色）
- [ ] 刪除按鈕位於卡片右上角，紅色 hover 效果
- [ ] 刪除中顯示載入狀態
- [ ] 空白清單顯示提示訊息
- [ ] 既有 watchlist CRUD 邏輯完全保留

- US-010（設計系統主題）
- US-011（版面結構）
