### US-012：重新設計股價查詢與結果卡片

**作為** 使用者
**我想要** 查詢股價的輸入區與結果顯示改為設計樣本的 bento grid 風格
**以便** 更直覺地閱讀即時股價資訊與當日走勢

**輸入格式**：
- 現有 `page.tsx` 的 `handleQuery`、`stockData`、`chartData`、`queryLoading`、`queryError`、`symbolError` 等狀態與邏輯（功能不變）
- 設計樣本 `code.html` 的「Quick Query」區塊與「Result Card + Chart」區塊
- 12 欄 grid 系統（來自 US-011 的版面結構）

**輸出格式**：
- **Quick Query 卡片**：
  - `QUICK QUERY` label（`label-caps` 樣式）
  - 搜尋 input（含 magnifying glass icon）+ Query 按鈕水平排列
  - 輸入驗證錯誤訊息保留，樣式改為設計系統風格
- **Result Card**（`lg:col-span-8`）：
  - 公司資訊區：ticker + 公司全名 + 產業標籤（`rounded-full` 徽章）
  - 股價價格區：大號 display 數字 + 漲跌金額與百分比（TWSE 紅漲綠跌）
  - 當日走勢圖：高度 `h-48`，使用 Recharts 折線圖，線條顏色紅漲綠跌，含昨收參考線
  - 底部 OHLC 網格：OPEN / HIGH / LOW / VOLUME 四個數據方塊
- 保留昨收參考線、Tooltip、Y 軸 domain 自動縮放等現有圖表功能
- 載入中狀態與錯誤提示保留，樣式更新為設計系統

**驗收條件**：
- [ ] Quick Query 卡片標題顯示「QUICK QUERY」label
- [ ] 輸入框有搜尋圖示，placeholder 顯示「e.g. 2330.TW」
- [ ] Query 按鈕為 primary 藍色，hover 有效果
- [ ] 輸入驗證錯誤以紅色文字顯示在輸入框下方
- [ ] 查詢結果顯示在 bento grid 左側 8 欄卡片中
- [ ] 公司名稱以大標題顯示，旁邊有產業類別徽章
- [ ] 股價以 `display-lg` 字級顯示，漲跌金額與百分比以 TWSE 紅漲綠跌顯示
- [ ] 走勢圖高度 192px，使用 Recharts 繪製
- [ ] 圖表線條顏色隨漲跌變化（漲紅跌綠），昨收參考線存在
- [ ] OHLC 四個數據以 4 欄網格顯示，label 使用 `label-caps` 樣式
- [ ] 載入中有 spinner 或提示
- [ ] 查詢錯誤顯示在卡片中
- [ ] 既有查詢邏輯完全保留

**依賴關係**：
- US-010（設計系統主題）
- US-011（版面結構與 grid 系統）

**優先級**：P0
**相關功能**：股價查詢與顯示
