### US-011：建立頂部導覽列與側邊欄

**作為** 使用者
**我想要** 看到固定的頂部導覽列與側邊導覽欄
**以便** 快速切換功能頁面並掌握目前市場狀態

**輸入格式**：
- 設計樣本 `code.html` 的 TopNavBar 結構（品牌名稱、搜尋列、更新計時器、通知/設定/帳戶圖示）
- 設計樣本 `code.html` 的 SideNavBar 結構（Market Data 區塊、導覽連結、Set Price Alert 按鈕、Telegram Bot/Support 連結）
- 現有 `page.tsx` 的內容需被包裹進新的版面結構

**輸出格式**：
- **TopNavBar**：sticky top-0，白色背景，包含：
  - 品牌名稱「ZenTrade TW」
  - 搜尋 input（`w-96`，僅 lg 以上顯示）
  - 更新計時器徽章（`Next update in Xs`，含旋轉 sync icon）
  - 通知、設定、帳戶圖示按鈕（Material Symbols）
- **SideNavBar**：fixed/sticky 左側欄（`w-64`），包含：
  - Market Data 資訊區塊
  - Dashboard / Watchlist / Alerts 導覽連結（active 狀態高亮）
  - Set Price Alert 按鈕
  - Telegram Bot / Support 底部連結
- **Layout container**：`max-w-[1280px]` 置中，sidebar + main 水平排列
- 行動版 sidebar 隱藏（`hidden md:flex`）

**驗收條件**：
- [ ] TopNavBar 在頁面頂部固定顯示（sticky），不隨內容滾動
- [ ] 品牌名稱「ZenTrade TW」使用 `headline-md` 字體樣式
- [ ] 搜尋 input 在 lg 以上寬度顯示，含 magnifying glass icon 與 placeholder「Search stocks...」
- [ ] 更新計時器顯示剩餘秒數，sync 圖示有旋轉動畫
- [ ] 通知、設定、帳戶圖示點擊有 hover 效果
- [ ] SideNavBar 左側固定顯示，寬度 256px
- [ ] Dashboard 導覽為 active 狀態（藍色背景）
- [ ] Watchlist / Alerts 有 hover 效果
- [ ] Set Price Alert 為藍色 primary 按鈕
- [ ] 主要內容區域在 sidebar 右側，不重疊
- [ ] 整體佈局在 1280px 以上置中，兩側留白
- [ ] 行動版（<768px）sidebar 隱藏，內容區滿版
- [ ] 所有既有功能在版面調整後仍正常運作

**依賴關係**：
- US-010（設計系統主題配色需先套用）

**優先級**：P0
**相關功能**：版面導覽結構
