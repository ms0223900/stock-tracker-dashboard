### US-012：追蹤清單支援幣別儲存與顯示

**作為** 使用者
**我想要** 儲存追蹤項目時一併記錄幣別，重新整理頁面後仍能看到正確的幣別資訊
**以便** 我追蹤不同市場的股票時不會混淆計價貨幣

**輸入格式**：
- `StockPrice.currency`（由 US-010 解析，例如 `"TWD"`、`"USD"`）
- 現有 `watchlist` 資料表結構與 `WatchlistItem` 型別

**輸出格式**：

**資料庫**：
- 新增 migration `002_add_currency.sql`，在 `watchlist` 資料表新增 `currency` 欄位：
  - `currency TEXT NOT NULL DEFAULT 'TWD'`
- 寫入 migration 檔案 `supabase/migrations/002_add_currency.sql`

**型別**：
- `WatchlistItem` 型別新增 `currency: string` 欄位

**儲存邏輯**（`hooks/useWatchlist.ts`）：
- `handleSave()` 從 `stockData.currency` 讀取並寫入 `watchlist` 資料表的 `currency` 欄位
- 向下相容不影響既有的舊資料（預設 `'TWD'`）

**顯示邏輯**（`components/WatchlistCard.tsx`）：
- `formatPrice(item.last_price, item.currency)`
- `formatPrice(item.target_price, item.currency)`

**後端排程**（`app/api/check-prices/route.ts`）：
- `fetchStockPriceServer` 回傳的 `currency` 僅供記錄，不影響比價邏輯

**驗收條件**：
- [ ] 執行 migration 後 `watchlist` 資料表有 `currency` 欄位
- [ ] 儲存 2330.TW 時 DB 記錄 `currency = 'TWD'`
- [ ] 重新整理頁面後 watchlist 仍顯示正確的幣別前綴
- [ ] 既有資料（無 `currency` 欄位）顯示 `NT$` 前綴，不報錯
- [ ] 追蹤清單可同時顯示多種幣別的股票（如 TWD + USD 混排）

**依賴關係**：
- US-010（解析 Yahoo Finance 幣別資訊）
- US-005（既有 Supabase migration 基礎）
- US-008（既有追蹤清單 CRUD）

**優先級**：P1
**相關功能**：追蹤清單、資料庫 migration
