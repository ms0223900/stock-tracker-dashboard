### US-002：實作輸入驗證與錯誤提示

**作為** 使用者
**我想要** 在輸入格式不正確時看到明確的提示
**以便** 我知道如何修正輸入內容

**輸入格式**：
- 股票代號字串
- 目標股價字串（數字）

**輸出格式**：
- 股票代號不符合 `.TW` 結尾格式時顯示「請輸入完整股票代號，例如 2330.TW」
- 目標股價為空白、非數字、0 或負數時顯示「請輸入大於 0 的目標股價」
- 通過驗證的輸入可正常提交

**驗收條件**：
- [x] 輸入 `台積電`、`2330`（無 .TW）或空白時，提示「請輸入完整股票代號，例如 2330.TW」
- [x] 目標股價為空白、`abc`、`0` 或 `-100` 時，提示「請輸入大於 0 的目標股價」
- [x] 驗證失敗時不呼叫 API，不寫入資料庫
- [x] 錯誤提示清楚顯示在對應輸入欄位附近
- [x] 修正輸入後錯誤提示消失

#### 驗收說明

**整體結論**：PASS ✅

> 股票代號與目標價驗證、`handleQuery`／`handleSave` 的早期 return、欄位旁錯誤與輸入時清除，皆與 AC 對齊。

---

**AC-1：[無效代號提示「請輸入完整股票代號…」]**

狀態：✅ 通過

- `lib/validation.ts` 的 `validateSymbol()` 對空白或非 `*.TW` 格式回傳指定繁中錯誤。
- `components/StockQueryForm.tsx` 於欄位下顯示 `symbolError`。

---

**AC-2：[無效目標價提示「請輸入大於 0 的目標股價」]**

狀態：✅ 通過

- `lib/validation.ts` 的 `validateTargetPrice()` 涵蓋空白、非數字、`<= 0`。

---

**AC-3：[驗證失敗不呼叫 API、不寫入 DB]**

狀態：✅ 通過

- `hooks/useStockQuery.ts`：`validateSymbol` 失敗時 `return`，不進入 fetch。
- `hooks/useWatchlist.ts`：`validateTargetPrice` 失敗時 `return`，不執行 `supabase.insert`。

---

**AC-4：[錯誤提示顯示在對應輸入欄位附近]**

狀態：✅ 通過

- `StockQueryForm`、`components/TargetPriceForm.tsx`（`targetPriceError`）於對應欄位附近顯示錯誤文字。

---

**AC-5：[修正輸入後錯誤提示消失]**

狀態：✅ 通過

- `useStockQuery` 的 `onSymbolChange`、`useWatchlist` 的 `onTargetPriceChange` 在有上一次錯誤時將錯誤狀態清為 `null`。

**依賴關係**：無（可獨立開發）
**優先級**：P0
**相關功能**：spec §5 使用者輸入、§11 驗收條件
