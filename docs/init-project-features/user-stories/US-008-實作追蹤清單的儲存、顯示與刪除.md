### US-008：實作追蹤清單的儲存、顯示與刪除

**作為** 使用者
**我想要** 儲存股票代號與目標股價、查看追蹤清單、刪除不需要的項目
**以便** 管理我的股價追蹤設定

**輸入格式**：
- 已驗證的股票代號與目標股價
- 點擊「儲存追蹤」按鈕
- 點擊刪除按鈕（P1）

**輸出格式**：
- 成功儲存後，追蹤清單更新顯示最新資料
- 清單每筆顯示：股票代號、目標股價、目前股價（若有）、通知狀態
- 刪除後該筆從清單移除

**驗收條件**：
- [x] 輸入 `2330.TW` 與 `2200` 點擊儲存，Supabase `watchlist` 新增一筆資料
- [x] 儲存後畫面追蹤清單立即更新
- [x] 頁面刷新後仍可看到之前儲存的追蹤項目
- [x] 儲存失敗時畫面顯示錯誤提示
- [x] (P1) 可點擊刪除按鈕移除追蹤項目，Supabase 與畫面同步更新
- [x] 目標股價未輸入時不觸發儲存

#### 驗收說明

**整體結論**：PARTIAL ⚠️

> Client 對 `watchlist` 的新增／讀取／刪除、儲存前驗證、載入輪詢與畫面上的代號／目標價／`last_price`／通知徽章大致齊備；刪除失敗僅 `console.error`，使用者看不到繁中錯誤提示。

---

**AC-1：[儲存 2330.TW + 2200 寫入 Supabase]**

狀態：✅ 通過

- `hooks/useWatchlist.ts` 的 `handleSave()` 於驗證通過後 `supabase.from("watchlist").insert({ symbol, target_price, last_price })`。

---

**AC-2：[儲存後清單立即更新]**

狀態：✅ 通過

- 成功後 `await fetchWatchlist()` 重新拉取並 `setWatchlist`。

---

**AC-3：[刷新後仍存在]**

狀態：✅ 通過

- `useWatchlistPolling` mount 時 `fetchWatchlist()`；資料存於 DB 後重新整理頁面仍會被查詢出。

---

**AC-4：[儲存失敗顯示錯誤]**

狀態：✅ 通過

- insert 錯誤時 `setSaveError('儲存失敗：…')`，`TargetPriceForm` 顯示。

---

**AC-5：[(P1) 刪除同步 DB 與畫面]**

狀態：⚠️ 部分實作

- `handleDelete()` 呼叫 `delete().eq("id")` 後一律 `fetchWatchlist()`。
- **差異說明**：`error` 時僅 console，無對應畫面提示；使用者可能無法區分「刪除成功與否」。（若無 error，列表與 DB 會一致）

---

**AC-6：[目標未輸入不觸發儲存]**

狀態：✅ 通過

- `validateTargetPrice` 失敗時 `return`，不觸發 `insert`。

---

**後續建議**

- 刪除失敗時比照儲存，呈現繁中錯誤訊息（例如 toast 或區塊內文字）。
