### US-008：實作追蹤清單的儲存、顯示與刪除

**作為** 使用者
**我想要** 儲存股票代號與目標股價、查看追蹤清單、刪除不需要的項目
**以便** 管理我的股價追蹤設定

**輸入格式**：
- 已驗證的股票代號與目標股價
- 點擊「儲存追蹤」按鈕
- 點擊刪除按鈕（P1）

**輸出格式**：
- 成功儲存後，追蹤清單更新顯示最新資料
- 清單每筆顯示：股票代號、目標股價、目前股價（若有）、通知狀態
- 刪除後該筆從清單移除

**驗收條件**：
- [ ] 輸入 `2330.TW` 與 `2200` 點擊儲存，Supabase `watchlist` 新增一筆資料
- [ ] 儲存後畫面追蹤清單立即更新
- [ ] 頁面刷新後仍可看到之前儲存的追蹤項目
- [ ] 儲存失敗時畫面顯示錯誤提示
- [ ] (P1) 可點擊刪除按鈕移除追蹤項目，Supabase 與畫面同步更新
- [ ] 目標股價未輸入時不觸發儲存

**依賴關係**：US-005（Supabase 連線）、US-002（輸入驗證）
**優先級**：P0
**相關功能**：spec §4 必做、§7 資料模型、§9 儲存追蹤流程
