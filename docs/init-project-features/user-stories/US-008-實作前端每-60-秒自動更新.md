### US-008：實作前端每 60 秒自動更新（P1）

**作為** 使用者
**我想要** 畫面每 60 秒自動重新取得股價
**以便** 不用手動刷新就能看到最新股價變化

**輸入格式**：
- 目前顯示的股票代號（若有查詢）
- 追蹤清單中的所有股票代號

**輸出格式**：
- 每 60 秒自動更新股價資訊區（若正在查看某支股票）
- 每 60 秒自動更新追蹤清單中的 `last_price`
- 更新時不中斷使用者操作，不顯示全域 loading

**驗收條件**：
- [ ] 股價查詢後，每 60 秒自動重新 fetch 最新股價
- [ ] 追蹤清單中的 `last_price` 每 60 秒自動更新
- [ ] 自動更新時不閃爍或中斷使用者正在輸入的內容
- [ ] 頁面切換或卸載時停止輪詢

**依賴關係**：US-003（股價查詢 UI）、US-005（追蹤清單顯示）
**優先級**：P1
**相關功能**：spec §4 最好有
