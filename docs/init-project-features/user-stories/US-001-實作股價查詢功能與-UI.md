### US-001：實作股價查詢功能與 UI

**作為** 使用者
**我想要** 輸入台股股票代號並查詢目前股價
**以便** 查看即時股價、今日高低價、開盤價與成交量

**輸入格式**：
- 使用者在 input 中輸入股票代號（例如 `2330.TW`）
- 點擊「查詢股價」按鈕

**輸出格式**：
- 畫面顯示：股票代號、目前價格、更新時間
- 若 API 有提供：今日最高價、最低價、開盤價、成交量
- 查詢中顯示 loading 狀態
- 查詢失敗顯示錯誤訊息

**驗收條件**：
- [ ] 輸入 `2330.TW` 點擊查詢，畫面顯示目前股價與更新時間
- [ ] 顯示今日最高價、最低價、開盤價、成交量（若 API 有提供）
- [ ] 查詢期間按鈕顯示 loading 狀態，防止重複送出
- [ ] API 失敗時畫面顯示「目前無法取得股價資料，請稍後再試」
- [ ] 股價資訊區在未查詢前不顯示，查詢成功後才出現

**依賴關係**：US-006（Yahoo Finance 模組）
**優先級**：P0
**相關功能**：spec §4 必做、§6 UI 範圍、§9 查詢股價流程
