### US-011：實作多幣別價格格式化與顯示

**作為** 使用者
**我想要** 看到正確的幣別符號與格式（例如 NT$1,205.00、$150.25、HK$280.00）
**以便** 我知道查詢的股價是以哪種貨幣計價

**輸入格式**：
- `StockPrice.currency`（由 US-010 解析）
- `.env` 無需額外設定，幣別資訊來自 Yahoo Finance API

**輸出格式**：
- `formatPrice()` 改為接受 `(n: number | null, currency?: string)`，根據 `currency` 決定前綴符號：
  - `"TWD"` → `NT$1,205.00`
  - `"USD"` → `$150.25`（美元慣例無空格）
  - `"HKD"` → `HK$280.00`
  - `"JPY"` → `¥15,000`（ JPY 小數位為 0）
  - `"KRW"` → `₩85,000`（KRW 小數位為 0）
  - `"EUR"` → `€120.50`
  - `"GBP"` → `£100.25`
  - `"SGD"` → `S$1.50`
  - 未匹配或未提供 → `TWD 1,205.00`（向後相容）
- `formatPrice` 需根據常見幣別調整小數位數：
  - JPY、KRW 等零小數幣別 → `maximumFractionDigits: 0`
  - 其餘維持 2 位小數
- `StockResultCard` 中原本 hardcode 的 `TWD` 文字改為顯示 `stockData.currency`
- `WatchlistCard` 中 `formatPrice` 調用需傳入對應幣別

**驗收條件**：
- [x] 查詢 `2330.TW` 顯示 `NT$1,205.00`
- [x] 查詢 `AAPL` 顯示 `$150.25`（USD）
- [x] 查詢 `9988.HK` 顯示 `HK$280.00`
- [x] JPY 計價股票顯示 `¥15,000`（無小數位）
- [x] 追蹤清單中的價格也使用正確幣別前綴
- [x] 圖表 tooltip 中的價格也使用正確幣別前綴
- [x] 無 `currency` 資訊時降級顯示 `TWD` 前綴
- [x] 股價結果卡價格下方幣別標籤顯示 `stockData.currency`（查詢 `AAPL` 時為 `USD`，不得寫死 `TWD`）

#### 驗收說明

**整體結論**：PASS ✅

> `formatPrice` 依 `CURRENCY_CONFIG` 格式化多幣別；`StockResultCard` 價格、圖表 tooltip／標籤皆傳入 `stockData.currency`；幣別代碼標籤已改為 `{stockData.currency}`，不再 hardcode `TWD`。
