### US-007：實作當日股價走勢折線圖（P1）

**作為** 使用者
**我想要** 查看當日股價走勢折線圖
**以便** 直觀了解股價變化趨勢

**輸入格式**：
- Yahoo Finance API 回應中的 timestamp 與 price 陣列資料

**輸出格式**：
- 使用 Recharts 繪製的折線圖
- X 軸為時間（HH:mm 格式），Y 軸為股價
- 查詢成功後在股價資訊下方顯示

**驗收條件**：
- [ ] 查詢股價後顯示當日走勢折線圖
- [ ] 圖表使用 Recharts 繪製，X 軸為時間、Y 軸為股價
- [ ] 圖表有適當的標題與軸標籤
- [ ] 無資料時不顯示空白圖表
- [ ] RWD：在不同螢幕寬度下圖表正常顯示

**依賴關係**：US-002（Yahoo Finance 模組）、US-003（股價查詢 UI）
**優先級**：P1
**相關功能**：spec §4 最好有、§2 精簡版需求文件折線圖
