### US-003：實作前端每 60 秒自動更新（P1）

**作為** 使用者
**我想要** 畫面每 60 秒自動重新取得股價
**以便** 不用手動刷新就能看到最新股價變化

**輸入格式**：
- 目前顯示的股票代號（若有查詢）
- 追蹤清單中的所有股票代號

**輸出格式**：
- 每 60 秒自動更新股價資訊區（若正在查看某支股票）
- 每 60 秒自動更新追蹤清單中的 `last_price`
- 更新時不中斷使用者操作，不顯示全域 loading

**驗收條件**：
- [x] 股價查詢後，每 60 秒自動重新 fetch 最新股價
- [x] 追蹤清單中的 `last_price` 每 60 秒自動更新
- [x] 自動更新時不閃爍或中斷使用者正在輸入的內容
- [x] 頁面切換或卸載時停止輪詢

#### 驗收說明

**整體結論**：PARTIAL ⚠️

> 輪詢間隔、卸載清理、更新目前查詢股價與清單 `last_price`、避免輪詢觸發 `fetchWatchlist` 全套 loading，皆已落在程式碼；AC-3「不中斷輸入／不閃爍」仍以 🔍 建議手動確認。

---

**AC-1：[查詢後每 60 秒自動 fetch 最新股價]**

狀態：✅ 通過

- `hooks/useWatchlistPolling.ts`：`pollWatchlist()` 在有 `stockDataRef.current?.symbol` 時呼叫 `fetchStockPrice`，並 `setStockData(data)`。
- `lib/constants.ts`：`POLL_INTERVAL_MS = 60000`。

---

**AC-2：[追蹤清單 last_price 每 60 秒更新]**

狀態：✅ 通過

- `useWatchlistPolling.ts`：對清單每筆 fetch 後 `setWatchlist` 更新 `last_price`、`previousClose`。

---

**AC-3：[自動更新不中斷輸入、不閃爍]**

狀態：🔍 需人工確認

- 輪詢不會調用 `fetchWatchlist` 的例行重新載入（僅初始化一次），可避免清單整頁進入 skeleton；亦不修改股票代號或目標價 input 的 controlled value。
- 父層重新 render 對焦／選取是否在少數瀏覽器造成干擾，建議手動打一長段字並等待輪詢驗證。

---

**AC-4：[頁面卸載時停止輪詢]**

狀態：✅ 通過

- `useWatchlistPolling.ts`：`useEffect` return `() => clearInterval(interval)`。

**依賴關係**：US-001（股價查詢 UI）、US-008（追蹤清單顯示）
**優先級**：P1
**相關功能**：spec §4 最好有
