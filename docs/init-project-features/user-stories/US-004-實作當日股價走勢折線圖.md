### US-004：實作當日股價走勢折線圖（P1）

**作為** 使用者
**我想要** 查看當日股價走勢折線圖
**以便** 直觀了解股價變化趨勢

**輸入格式**：
- Yahoo Finance API 回應中的 timestamp 與 price 陣列資料

**輸出格式**：
- 使用 Recharts 繪製的走勢圖（實作為 `AreaChart`）
- X 軸為時間（HH:mm 格式），Y 軸為股價
- 查詢成功後在股價資訊下方顯示
- **圖上「區間最高／最低」標記**：在 `chartData`（`timestamp` + `quote.close`）序列上取價格最大／最小之數據點，以 ReferenceDot（及輔助 ReferenceLine）標出；詳見 `docs/spec.md`「最高／最低價」第 2 點——與 OHLC 網格之「最高」「最低」可能數值不同

**驗收條件**：
- [x] 查詢股價後顯示當日走勢折線圖
- [x] 圖表使用 Recharts 繪製，X 軸為時間、Y 軸為股價
- [x] 圖表有適當的標題與軸標籤
- [x] 無資料時不顯示空白圖表
- [x] RWD：在不同螢幕寬度下圖表正常顯示
- [x] 有 `chartData` 時，圖上以 close 序列之最大值與最小值標示高／低點（與 spec 定義一致）
