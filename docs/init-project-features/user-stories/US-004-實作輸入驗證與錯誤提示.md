### US-004：實作輸入驗證與錯誤提示

**作為** 使用者
**我想要** 在輸入格式不正確時看到明確的提示
**以便** 我知道如何修正輸入內容

**輸入格式**：
- 股票代號字串
- 目標股價字串（數字）

**輸出格式**：
- 股票代號不符合 `.TW` 結尾格式時顯示「請輸入完整股票代號，例如 2330.TW」
- 目標股價為空白、非數字、0 或負數時顯示「請輸入大於 0 的目標股價」
- 通過驗證的輸入可正常提交

**驗收條件**：
- [ ] 輸入 `台積電`、`2330`（無 .TW）或空白時，提示「請輸入完整股票代號，例如 2330.TW」
- [ ] 目標股價為空白、`abc`、`0` 或 `-100` 時，提示「請輸入大於 0 的目標股價」
- [ ] 驗證失敗時不呼叫 API，不寫入資料庫
- [ ] 錯誤提示清楚顯示在對應輸入欄位附近
- [ ] 修正輸入後錯誤提示消失

**依賴關係**：無（可獨立開發）
**優先級**：P0
**相關功能**：spec §5 使用者輸入、§11 驗收條件
