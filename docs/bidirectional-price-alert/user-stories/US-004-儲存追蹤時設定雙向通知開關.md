### US-004：儲存追蹤時設定雙向通知開關

**作為** 投資者
**我想要** 在設定目標價時分別勾選「價格以上」與「價格以下」是否通知
**以便** 依策略只追蹤突破或跌破

**輸入格式**：
- 查詢結果之 `StockPrice`、目標價字串、兩個布林開關（預設：以上=true、以下=false）
- 既有 [`validateTargetPrice`](../../../lib/validation.ts) 與 Supabase insert（[`hooks/useWatchlist.ts`](../../../hooks/useWatchlist.ts)）

**輸出格式**：
- [`components/StockResultCard.tsx`](../../../components/StockResultCard.tsx) 顯示兩個可切換控制項與說明文字（例如「當股價 ≥ 目標價時通知」「當股價 ≤ 目標價時通知」）
- [`lib/validation.ts`](../../../lib/validation.ts) 新增 `validateNotifyDirections(notifyAbove, notifyBelow)`，全關時回傳錯誤「請至少選擇一種通知方向」
- `useWatchlist.handleSave` 寫入 `notify_above`、`notify_below`
- [`components/QueryAndTrackCard.tsx`](../../../components/QueryAndTrackCard.tsx) 說明文字更新為雙向通知語意

**驗收條件**：
- [ ] 預設僅「價格以上」勾選，與舊版體驗一致
- [ ] 可只勾「以下」、只勾「以上」、或兩者皆勾
- [ ] 兩者皆未勾選時顯示 inline 錯誤「請至少選擇一種通知方向」，不呼叫 insert
- [ ] insert payload 含 `notify_above`／`notify_below`，DB 可查且符合 CHECK 約束
- [ ] 目標價驗證失敗時不寫入 DB（沿用既有行為）

**依賴關係**：
- US-001

**優先級**：P0
**相關功能**：儲存追蹤、輸入驗證
