# 雙向到價通知 — User Stories 一覽

本目錄對應 [`../spec.md`](../spec.md)：在既有「價格 ≥ 目標價」通知基礎上，支援「價格 ≤ 目標價」通知，且兩方向可**分別開關**設定。

---

## US 一覽表

| US | 標題 | 優先級 | 依賴 | 簡要說明 |
| --- | --- | --- | --- | --- |
| **001** | 雙向到價通知規格與 watchlist 資料模型擴充 | P0 | — | migration、型別、子 spec；舊資料向後相容 |
| **002** | 後端雙向達標判定與獨立通知狀態更新 | P0 | US-001、US-003 同波 | `runWatchlistPriceCheck` 雙向獨立觸發與標記 |
| **003** | 區分方向的通知文案（Telegram／LINE） | P0 | US-001、US-002 同波 | 「向上突破」／「向下跌破」文案 |
| **004** | 儲存追蹤時設定雙向通知開關 | P0 | US-001 | UI 開關、驗證、insert 新欄位 |
| **005** | 追蹤清單顯示雙向通知設定與狀態 | P0 | US-001、US-002、US-004 | 卡片顯示方向與各方向通知狀態 |

> **重要**：US-002 與 US-003 **必須同一 PR／同一波次交付**，不得單獨關閉 US-003，避免 below 已觸發卻仍送舊版文案。

## 依賴說明

- **US-001** 為契約基礎：無前置 US，但需既有 `watchlist` 表。
- **US-002／US-003** 緊密耦合，須同波交付；依賴 US-001 新欄位。
- **US-004** 僅需 US-001 即可開發（可先寫入 `notify_*`，後端未更新前 below 不會觸發）。
- **US-005** 需 US-002 實際更新 `is_notified_*` 後才能完整驗收通知狀態。
- **US-006** 待 US-001～005 定案後更新主 spec，避免文件漂移。

## 產品決策摘要

| 決策 | 內容 |
| --- | --- |
| 目標價 | 單一 `target_price`，以上／以下共用 |
| 觸發 | above：`≥`；below：`≤`；各方向獨立、各通知一次 |
| 預設 | 僅「以上」啟用（`notify_above=true`, `notify_below=false`） |
| 邊界 | `price === target` 且雙開：同一輪可各發一則 |
| 編輯 | 不支援修改既有項目開關（刪除重加） |

詳見 [`../spec.md`](../spec.md)。
