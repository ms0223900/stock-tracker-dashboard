### US-005：追蹤清單顯示雙向通知設定與狀態

**作為** 投資者
**我想要** 在追蹤清單卡片上看到設定了哪些通知方向及各自是否已通知
**以便** 掌握每筆追蹤的提醒狀態

**輸入格式**：
- `WatchlistItem` 含 `notify_above`、`notify_below`、`is_notified_above`、`is_notified_below`、`notified_at_above`、`notified_at_below`
- 既有 [`components/WatchlistCard.tsx`](../../../components/WatchlistCard.tsx) 卡片佈局

**輸出格式**：
- 卡片顯示啟用的方向（例如「以上通知」「以下通知」小標籤或圖示說明）
- 狀態徽章依方向顯示，例如：
  - 僅 above 啟用且已通知：「已通知（以上）」
  - 僅 below 啟用且追蹤中：「追蹤中」
  - 雙向啟用、above 已通知、below 未通知：同時顯示「已通知（以上）」與「追蹤中（以下）」
- 若有 `notified_at_*` 顯示對應時間

**驗收條件**：
- [ ] 僅啟用 above 時 UI 不顯示 below 相關誤導資訊
- [ ] 雙向啟用且僅一方向已通知時，另一方向仍顯示追蹤中
- [ ] 與輪詢更新後的 DB 狀態一致（`fetchWatchlist`／`mergeWatchlistFromDb` 正確帶回新欄位）
- [ ] 響應式佈局不破壞既有卡片設計
- [ ] 已移除對舊 `is_notified` 的依賴

**依賴關係**：
- US-001
- US-004（insert 含 notify 欄位）
- US-002（實際更新 `is_notified_*` 後方可驗收通知狀態）

**優先級**：P0
**相關功能**：追蹤清單 UI
