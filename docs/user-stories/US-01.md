# US-01：即時股價查詢

## 與 spec 範圍

本 US 涵蓋 `docs/spec.md` §4 **必做**：查詢即時股價、錯誤訊息，以及 **「若 API 提供資料，顯示今日最高價、最低價、開盤價與成交量」**（OHLC 網格語意見 §8 第 1 點，與走勢圖極值不同）。**走勢面積圖、sparkline、刪除追蹤**屬 spec §4「最好有」，請見 **US-05**。

## User Story

**作為** 使用者，
**我想** 輸入股票代號並查詢即時股價，
**這樣** 我就能確認系統有正確抓取到股票資料。

## Acceptance Criteria

- [x] AC1：輸入 `2330.TW` 並送出後，系統呼叫 Yahoo Finance API。
- [x] AC2：查詢成功時，畫面顯示**股票代號、目前股價、幣別、更新時間**。
- [x] AC3：查詢中時，按鈕進入 disabled 狀態或顯示「查詢中」。
- [x] AC4：API 查詢失敗時，畫面顯示「目前無法取得股價資料，請稍後再試」。
- [x] AC5：股票代號為空時，不送出 API 請求，提示「請輸入有效股票代號，例如 2330.TW、AAPL、7000.HK」。
- [x] AC6：輸入 `台積電`、空白或含非英數字（`.` 除外）之字元時，提示相同格式錯誤訊息。
- [x] AC6b：**代號格式（定案）** 僅允許英文字母、數字，以及以 `.` 分隔之後綴（如 `2330.TW`、`AAPL`、`7000.HK`）；通過驗證後以**大寫**正規化（例如 `aapl` → `AAPL`）。
- [x] AC7：**必做（spec §4）** 查詢成功且 Yahoo 有提供對應欄位時，股價結果區須顯示**今日最高、最低、開盤、成交量**（正規化規則與 §8「OHLC 網格」一致；缺資料時可顯示合理 fallback，例如「—」或與既有 `formatPrice` 一致，**不可**因此讓整頁崩潰）。

## Technical Notes

- **股票代號驗證**（`lib/validation.ts` → `validateSymbol`）：正則 `^[A-Za-z0-9]+(\.[A-Za-z0-9]+)*$`；錯誤文案見 `lib/constants.ts` 之 `SYMBOL_FORMAT_ERROR`。
- **Endpoint**：`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`
- **Response 正規化**：須將 API response 轉換為內部型別 `StockPrice`，至少包含：
  - `symbol`、`price`、`currency`、`updateTime`
  - `high`、`low`、`open`、`volume`（**US-01 必做顯示**；US-05 走勢圖與 sparkline 另用 chartData，語意見 §8）
  - **建議**：一併正規化當日 **`chartData`**（`timestamp` 與 `quote.close` 對齊、略過 null），供 **US-05** 直接重用，避免為圖表二次請求 Yahoo（若時程緊可先回傳空陣列，但 US-05 開做時須補齊）
- **最高／最低價正規化規則**（依 spec §8）：
  - `high`：`quote.high` 陣列有效數值之最大值；無則取 `quote.close` 最大值；再無取最後一個有效值
  - `low`：`quote.low` 陣列有效數值之最小值；無則取 `quote.close` 最小值；再無取最後一個有效值
- **建議檔案**：`lib/yahoo-finance.ts`（API 呼叫與正規化）、`types/stock.ts`（型別定義）、`app/page.tsx`（UI）
- **架構原則**：Yahoo Finance 為公開 API、無 secret，**可**由瀏覽器直接請求以減少 MVP 檔案數。若遇 **CORS 或瀏覽器限制**，退路為新增 Route Handler 代理，行為與正規化仍應與本 US 一致。

## Design Reference

設計稿：`docs/design.pen`「股價看板」Frame

### 本 US 涵蓋的 UI 區塊

| 區塊 | 設計圖節點 | 關鍵規格 |
|---|---|---|
| **錯誤提示列** | `errorBanner` | 置頂橫幅，左側 4px 紅色邊框 + error icon + 文字訊息。背景 `$--secondary`，圓角 14px |
| **表單卡片** | `formCard` | 標題「查詢與追蹤」20px bold + 提示文字。內距 28px，圓角 16px，白底 `$--card` + `$--border` 描邊 |
| **股票代號輸入** | `symInput` | 高 48px，圓角 14px，內距 18px，灰底 `$--card-muted` + `$--border` 描邊。placeholder 文字 `2330.TW` |
| **查詢按鈕** | `queryBtn` | 灰底 `$--primary`，pill 圓角 999，search icon +「查詢股價」white label。loading 時改為 disabled 狀態 |
| **股價結果卡** | `resultCard` | 標題 = 股票代號 28px bold + 更新時間副標 13px。右上角大字價格 36px bold（`$--primary`）+ 幣別 13px |
| **OHLC 四格（必做）** | 對齊設計稿 `ohlcRow` 之**資訊內容** | 最高 · 最低 · 開盤 · 成交量；版式可先簡化（例如單列四格），**US-05 可再對齊**設計稿完整樣式與 chart 區塊 |

### 佈局層級

```
contentWrap (左右 padding 40px, max 1280px)
  └── content (vertical gap 16px)
       ├── errorBanner（錯誤提示）
       ├── formCard（查詢表單）
       └── resultCard（股價結果，初始隱藏，查詢後顯示；含必做 OHLC 四格；走勢圖見 US-05）
```

### 狀態對應

- **初始**：只顯示 errorBanner（若有錯誤） + formCard，resultCard 隱藏
- **查詢中**：queryBtn 改為 disabled +「查詢中」文字
- **成功**：顯示 resultCard，填入股價資料
- **失敗**：errorBanner 顯示錯誤訊息
- **空值防呆**：errorBanner 顯示「請輸入完整股票代號…」
