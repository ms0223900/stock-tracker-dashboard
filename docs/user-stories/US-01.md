# US-01：即時股價查詢

## User Story

**作為** 使用者，
**我想** 輸入完整台股股票代號並查詢即時股價，
**這樣** 我就能確認系統有正確抓取到股票資料。

## Acceptance Criteria

- [ ] AC1：輸入 `2330.TW` 並送出後，系統呼叫 Yahoo Finance API。
- [ ] AC2：查詢成功時，畫面顯示**股票代號、目前股價、幣別、更新時間**。
- [ ] AC3：查詢中時，按鈕進入 disabled 狀態或顯示「查詢中」。
- [ ] AC4：API 查詢失敗時，畫面顯示「目前無法取得股價資料，請稍後再試」。
- [ ] AC5：股票代號為空時，不送出 API 請求，提示「請輸入完整股票代號，例如 2330.TW」。
- [ ] AC6：輸入 `2330`（缺少 `.TW`）或 `台積電` 時，提示相同格式錯誤訊息。

## Technical Notes

- **Endpoint**：`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`
- **Response 正規化**：須將 API response 轉換為內部型別 `StockPrice`，至少包含：
  - `symbol`、`price`、`currency`、`updateTime`
  - `high`、`low`、`open`、`volume`（供後續 US-05 圖表使用）
- **最高／最低價正規化規則**（依 spec §8）：
  - `high`：`quote.high` 陣列有效數值之最大值；無則取 `quote.close` 最大值；再無取最後一個有效值
  - `low`：`quote.low` 陣列有效數值之最小值；無則取 `quote.close` 最小值；再無取最後一個有效值
- **建議檔案**：`lib/yahoo-finance.ts`（API 呼叫與正規化）、`types/stock.ts`（型別定義）、`app/page.tsx`（UI）
- **架構原則**：API 呼叫在 client 端直接發送（不需要 Route Handler 代理），減少 MVP 前期檔案數量

## Design Reference

設計稿：`docs/design.pen`「股價看板」Frame

### 本 US 涵蓋的 UI 區塊

| 區塊 | 設計圖節點 | 關鍵規格 |
|---|---|---|
| **錯誤提示列** | `errorBanner` | 置頂橫幅，左側 4px 紅色邊框 + error icon + 文字訊息。背景 `$--secondary`，圓角 14px |
| **表單卡片** | `formCard` | 標題「查詢與追蹤」20px bold + 提示文字。內距 28px，圓角 16px，白底 `$--card` + `$--border` 描邊 |
| **股票代號輸入** | `symInput` | 高 48px，圓角 14px，內距 18px，灰底 `$--card-muted` + `$--border` 描邊。placeholder 文字 `2330.TW` |
| **查詢按鈕** | `queryBtn` | 灰底 `$--primary`，pill 圓角 999，search icon +「查詢股價」white label。loading 時改為 disabled 狀態 |
| **股價結果卡** | `resultCard` | 標題 = 股票代號 28px bold + 更新時間副標 13px。右上角大字價格 36px bold（`$--primary`）+ 幣別 13px |

### 佈局層級

```
contentWrap (左右 padding 40px, max 1280px)
  └── content (vertical gap 16px)
       ├── errorBanner（錯誤提示）
       ├── formCard（查詢表單）
       └── resultCard（股價結果，初始隱藏，查詢後顯示）
```

### 狀態對應

- **初始**：只顯示 errorBanner（若有錯誤） + formCard，resultCard 隱藏
- **查詢中**：queryBtn 改為 disabled +「查詢中」文字
- **成功**：顯示 resultCard，填入股價資料
- **失敗**：errorBanner 顯示錯誤訊息
- **空值防呆**：errorBanner 顯示「請輸入完整股票代號…」

## Dependencies

- 無（第一張 US，可獨立開始）
