# US-備註-01：追蹤項目備註欄位

## 與 spec 範圍

本 US 對應 `docs/change-spec-1/change-spec-stock-memo.md`：在既有追蹤流程上新增**選填**「備註」欄位，讓使用者記錄追蹤原因。**不變更**通知邏輯、股價抓取、目標價驗收條件；除顯示備註所需調整外，不重構追蹤清單。

## User Story

**作為** 使用者，
**我想要** 在新增追蹤項目時填寫備註，並在追蹤清單中看到備註文字，
**以便** 記錄我追蹤該股票的原因，日後回顧時能快速理解當初的判斷依據。

## 輸入格式

- **新增追蹤表單**：既有欄位（股票代號、目標股價）之外，可選填 `memo`（備註）文字；留空視為無備註。
- **資料庫**：`watchlist` 表新增 `memo` 欄位（`text`，可為 `null` 或空字串）。
- **API／Server Action payload**（若沿用既有儲存流程）：`{ symbol, target_price, memo?: string }`。

## 輸出格式

- **儲存成功**：`watchlist` 一列含 `memo` 值（有填則寫入，未填則 `null` 或空字串）。
- **追蹤清單 UI**：每張卡片在有備註時顯示備註文字；無備註時不佔版面或顯示合理留白，**不影響**既有代號、目標價、目前股價、通知狀態等資訊。
- **既有流程**：股價輪詢、達標通知、`last_price` 寫入等行為與改動前一致。

## Acceptance Criteria

- [ ] AC1：使用者新增追蹤項目時，表單提供**選填**備註輸入（例如 textarea 或單行 input，文案如「備註（選填）」）。
- [ ] AC2：填寫備註並儲存成功後，Supabase `watchlist` 該筆資料含正確 `memo` 內容。
- [ ] AC3：備註留空並儲存時，寫入 `null` 或空字串，**既有儲存與驗證流程不受影響**（代號、目標價驗證規則同 US-02）。
- [ ] AC4：追蹤清單載入後，有備註的項目在卡片上**可讀**顯示備註文字（繁體中文 UI）。
- [ ] AC5：無備註的項目，清單版面與互動與改動前一致，不出現錯誤或異常空白區塊。
- [ ] AC6：**回歸** 前端 60 秒輪詢、股價更新、`last_price` 寫入仍正常（US-03）。
- [ ] AC7：**回歸** 達標 Telegram 通知與 `is_notified`／`notified_at` 邏輯仍正常，**不因 `memo` 欄位而改變**（US-04）。
- [ ] AC8：`memo` 僅為展示用選填欄位；**不新增**額外必填驗證或長度以外的複雜規則（若需上限，建議合理值如 500 字並在技術備註註明，非本 US 必做除非實作時發現必要）。

## Technical Notes

- **資料表變更**（`watchlist` 新增欄位）：

  | 欄位 | 型別 | 必填 | 說明 |
  |---|---|---|---|
  | `memo` | `text` | 否 | 使用者自填追蹤原因；預設 `null` |

- **型別**：`WatchlistItem`（或同等型別）須加入 `memo?: string | null`。
- **建議修改檔案**：
  - Supabase migration 或 schema 說明（`memo` 欄位）
  - `types/watchlist.ts`（型別）
  - 新增追蹤表單 UI（與 US-02 同一區塊，例如 `TargetPriceSection` 或 `page.tsx`）
  - `components/WatchlistCard.tsx`（清單顯示備註）
  - 儲存 watchlist 的 Server Action／Route Handler（帶入 `memo`）
- **邊界**：trim 前後空白；全空白視同未填。惡意超長輸入可於 server 端截斷或拒絕，錯誤須繁中可讀。
- **刻意不做**（見 change spec §4）：編輯／刪除備註、通知內容帶備註、搜尋篩選備註。

## Design Reference

- 備註輸入可置於目標股價輸入下方或表單卡片內，標示「選填」。
- 清單卡片：備註以次要文字色（`text-muted-foreground`）、較小字級顯示於代號或目標價附近；過長文字可 `line-clamp` 或換行，避免撐破卡片佈局。

## Dependencies

- **US-02**（追蹤項目儲存）：`watchlist` 表與寫入流程須已存在。
- **US-03**（追蹤清單顯示）：卡片結構為顯示備註的載體。
