# US-03：追蹤清單顯示與自動更新

## User Story

**作為** 使用者，
**我想** 看到我已儲存的追蹤股票清單，且系統會自動更新股價，
**這樣** 我就不用手動一筆一筆查詢。

## Acceptance Criteria

- [ ] AC1：頁面載入時從 Supabase 讀取 `watchlist` 全部資料。
- [ ] AC2：清單以卡片式佈局顯示，每張卡片包含**股票代號、目標股價、目前股價（若已有）、是否已通知狀態**。
- [ ] AC3：追蹤清單為空時，顯示空狀態提示（例如「尚未加入任何追蹤項目」），而非空白畫面。
- [ ] AC4：資料讀取中時，顯示載入狀態。
- [ ] AC5：讀取失敗時，畫面顯示繁體中文錯誤訊息。
- [ ] AC6：**新增追蹤項目後，清單自動更新**（不需手動重整頁面）。
- [ ] AC7：**前端輪詢每 60 秒觸發一次**，重新取得清單內**每一筆**股票的最新股價並更新 UI。
  - 含股價結果區（若目前有顯示查詢結果）與追蹤清單內全部卡片。
  - 單一股票查價失敗時，其餘股票與整頁仍維持可用。
- [ ] AC8：頁面離開或元件卸載時，停止輪詢（避免資源洩漏）。

## Technical Notes

- **輪詢實作**：建議使用 `useWatchlistPolling` custom hook，內部使用 `setInterval(60000)`，onCleanup 清除
- **輪詢刷新範圍**：每一輪須同時更新：
  1. 股價結果區（若目前仍顯示有效查詢結果）
  2. 追蹤清單內每筆卡片的 `last_price` 與更新時間
- **容錯設計**：迴圈遍歷每筆 `symbol` 個別查價，`Promise.allSettled` 確保單筆失敗不影響其他
- **UI 互動層**：此 US 還不處理達標通知（留給 US-04）
- **建議檔案**：
  - `hooks/useWatchlistPolling.ts`（輪詢邏輯）
  - `components/WatchlistCard.tsx`（單張卡片）
  - `components/WatchlistSection.tsx`（清單區塊，含空/載入/錯誤狀態）

## Design Reference

設計稿：`docs/design.pen`「股價看板」Frame

### 本 US 涵蓋的 UI 區塊

| 區塊 | 設計圖節點 | 關鍵規格 |
|---|---|---|
| **追蹤清單標題** | `wlHeader` | 標題「追蹤清單」20px bold + 副提示「每 60 秒更新 · sparkline 同主圖資料」13px |
| **追蹤卡片** | `wlCard1` / `wlCard2` | 圓角 16px，`$--card` 底 + `$--border` 描邊，內距 22px，vertical gap 14px |
| **卡片標題列** | `wl1Top` | 股票代號 17px bold（左）+ 刪除按鈕 trash-2 icon（右，本 US 先隱藏或 disabled） |
| **卡片價格列** | `wl1Mid` | 左側「最新價」12px label + 價格 22px bold（`$--primary`）；右側「目標」12px label + 目標價 16px semibold |
| **狀態徽章** | `wl1Tag` | 綠底 pill `$--color-success`，「追蹤中」11px semibold。若 `is_notified = true` 則改為「已達標通知」 |
| **空狀態** | （設計圖未繪製，需自行實作） | 建議置中文字「尚未加入任何追蹤項目」搭配 `$--muted-foreground` |

### 佈局層級

```
wlSection
  └── wlHeader（標題列）
  └── wlGrid (horizontal gap 16px)
       ├── wlCard1
       │    ├── wl1Top（代號 + 刪除）
       │    ├── wl1Mid（最新價 + 目標）
       │    └── wl1Badge（狀態徽章）
       └── wlCard2（同結構）
```

### 狀態對應

- **載入中**：wlGrid 內顯示 skeleton 或 loading spinner
- **空清單**：wlGrid 改為空狀態提示文字
- **載入失敗**：errorBanner 顯示錯誤
- **有資料**：wlGrid 內以 flex-wrap 排列卡片
- **輪詢進行中**：不需額外 UI 提示，價格數字自動更新即可
- **單筆查價失敗**：該卡片的價格顯示「—」維持版面，不影響其他卡片

### 設計圖注意

- wlGrid 目前只有 2 張卡片範例，實作時須改為動態列表
- 刪除按鈕在本 US 應先隱藏（留給 US-05），避免混淆 scope
- sparkline 區域在本 US 可先留空或顯示簡易佔位（留給 US-05）
