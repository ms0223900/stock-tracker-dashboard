# US-02：追蹤項目儲存

## User Story

**作為** 使用者，
**我想** 將股票代號與目標股價儲存到追蹤清單，
**這樣** 系統之後可以幫我監控價格是否達標。

## Acceptance Criteria

- [x] AC1：Supabase `watchlist` 資料表已建立，包含必要欄位（見技術備註）。
- [x] AC2：輸入股票代號與大於 0 的目標股價後按下儲存，資料寫入 Supabase。
- [x] AC3：儲存成功時，畫面顯示成功提示（例如「已加入追蹤清單」）。
- [x] AC4：目標股價為空白、`abc`、`0` 或負數時，畫面提示「請輸入大於 0 的目標股價」且不寫入資料庫。
- [x] AC5：股票代號為空白或格式錯誤時，不寫入資料庫並提示錯誤（格式規則同 **US-01 AC6b**：英數字，可含 `.` 後綴，例如 `2330.TW`、`AAPL`、`7000.HK`）。
- [x] AC6：儲存失敗時（網路錯誤、Supabase 連線失敗），畫面顯示可理解的錯誤訊息。
- [x] AC7：Supabase URL 與 Anon Key 從環境變數讀取，不寫死在程式碼中。

## Technical Notes

- **資料表 `watchlist` 欄位設計**（MVP 最小集合）：

  | 欄位 | 型別 | 必填 | 說明 |
  |---|---|---|---|
  | `id` | `uuid` | 是 | PK，`gen_random_uuid()` |
  | `symbol` | `text` | 是 | 股票代號，例如 `2330.TW`、`AAPL`、`7000.HK` |
  | `target_price` | `numeric` | 是 | 使用者設定的目標股價 |
  | `last_price` | `numeric` | 否 | 最近一次查到的股價（US-03 開始使用） |
  | `is_notified` | `boolean` | 是 | 預設 `false`（US-04 開始使用） |
  | `notified_at` | `timestamptz` | 否 | 通知成功時間（US-04 開始使用） |
  | `created_at` | `timestamptz` | 是 | 建立時間，預設 `now()` |
  | `updated_at` | `timestamptz` | 否 | 最後更新時間 |

- **環境變數**：`NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_ANON_KEY`
- **`SUPABASE_SERVICE_ROLE_KEY`（選用）**：見 `docs/spec.md` §10。僅在 **server**（Route Handler／Server Action）使用。若 MVP 以 anon key + 寬鬆 RLS 即可完成寫入，可不設；若 US-04 等 server 流程需繞過 RLS 寫入 `last_price`／通知狀態，則須於 **Vercel 設定** 並僅在後端讀取。
- **建議檔案**：`lib/supabase.ts`（client 初始化）、`app/page.tsx`（新增 UI）
- **RLS 策略**：MVP 階段可暫時開放 `INSERT` 權限（不涉及多使用者隔離），後續迭代再補
- **設計取捨**：本張 US 不處理「編輯」或「刪除」功能（留給 US-05）

## Design Reference

設計稿：`docs/design.pen`「股價看板」Frame

### 本 US 涵蓋的 UI 區塊

| 區塊 | 設計圖節點 | 關鍵規格 |
|---|---|---|
| **目標股價輸入** | `tgtInput` | 高 48px，寬 74px（內部 absolute 佈局），placeholder 文字 `2200`。位於 resultCard 右上 priceBlock 下方 |
| **儲存按鈕** | `saveBtn` | 灰底 `$--secondary`，pill 圓角 999，bell-ring icon +「儲存目標股價」15px semibold。位於目標價輸入右側 |
| **表單提示** | `formHint` | 位於 formCard 內，`$--muted-foreground` 14px，內容「格式須為 英數字；目標價須大於 0。達標後會發送通知。」 |

### 佈局層級（resultCard 右上區塊）

```
priceActionCol (vertical, align end)
  ├── priceBlock（US-01 股價主要）
  └── tgtSaveRow (horizontal, gap 12)
       ├── tgtCol（目標股價 label + input）
       └── saveBtn（儲存目標股價）
```

### 狀態對應

- **初始**：tgtInput 顯示 placeholder `2200`，saveBtn 正常狀態
- **儲存成功**：saveBtn 上方或全局顯示成功提示（設計圖中無專屬 node，可用 toast 或 inline message）
- **驗證失敗**：errorBanner 顯示「請輸入大於 0 的目標股價」
- **儲存失敗**：errorBanner 顯示網路錯誤訊息

### 設計注意

- 目標股價輸入與儲存按鈕只在「已有查詢結果」時才顯示（位於 resultCard 內），此 US 讓它們從隱藏變為可操作

## Dependencies
