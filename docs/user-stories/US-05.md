# US-05：走勢圖、Sparkline、刪除追蹤（spec「最好有」）

## 與 `docs/spec.md` 的對應（釐清「最好有」）

`spec` §4 **最好有**項目與本 US 對照如下。**必做**項目請勿以「未完成 US-05」為由跳過—對應關係已拆到 **US-01**／**US-03**／**US-04**。

| spec §4「最好有」 | 本 US 負責 |
|------------------|------------|
| 當日股價走勢折線圖（結果卡） | AC1、AC2、AC7 |
| 追蹤卡內 sparkline（資料同主圖 chartData） | AC3、AC7 |
| 基本刪除追蹤項目 | AC4、AC5、AC6 |
| Next.js API route + **Vercel Cron** 背景檢查 | **不在** MVP 必做路徑；spec 亦列為「最好有」且定案以**前端輪詢**為主，可另開任務或日後再做 |

### 與 US-01（OHLC 必做）的分工

- **必做**之「最高、最低、開盤、成交量」顯示屬 **US-01**（OHLC **網格**語意，§8 第 1 點）。
- 本 US 之 **設計稿 `ohlcRow`**：若 US-01 已用簡化四格滿足 spec，本 US 可將**同一元件**視覺對齊設計稿（色塊、圓角、排版），**不重複**第二套資料來源或正規化邏輯。
- **走勢圖上**之最高／最低**標記**（close 序列極值，§8 第 2 點）屬本 US，且與 OHLC 網格數值**可能不同**，屬預期行為。

### 與 spec §6「畫面至少包含」

spec §6 列有追蹤區「sparkline」與結果區走勢—與 §4「最好有」並列時，**以 §4 為產品範圍准據**（prototype／課程 MVP）：未完成本 US 仍可驗收必做核心；§6 視為**完整 UI 目標**，與設計稿一致時須做完本 US（或於 spec 修訂時寫明例外）。

## User Story

**作為** 使用者，
**我想** 在股價結果卡看到當日走勢圖、在追蹤卡片看到 sparkline，並且可以刪除追蹤項目，
**這樣** 我能快速掌握價格趨勢並管理我的清單。

## Acceptance Criteria

- [ ] AC1：股價結果區（StockResultCard）顯示當日股價走勢**面積圖（AreaChart）**。
- [ ] AC2：走勢圖上標示當日**最高價與最低價位置**（ReferenceDot / ReferenceLine；語意為 **chartData／close 序列**極值，見 spec §8 第 2 點，**不等同** OHLC 網格之 high／low）。
- [ ] AC3：追蹤清單每張卡片（WatchlistCard）內含 sparkline 折線圖。
- [ ] AC4：每張追蹤卡片有「刪除」按鈕，點擊後出現確認提示。
- [ ] AC5：刪除確認後，該筆資料自 Supabase 移除，清單即時更新。
- [ ] AC6：刪除失敗時，畫面顯示錯誤訊息。
- [ ] AC7：圖表與 sparkline 資料來源為 Yahoo Finance 回傳之當日 **chartData**（`timestamp` + `quote.close`），首次查詢後即有完整線圖；**不需**為 sparkline 額外呼叫不同 endpoint。

## Technical Notes

- **圖表函式庫**：Recharts（`AreaChart`、`ReferenceDot`、`ReferenceLine`）
- **chartData 來源**：Yahoo Finance API 回傳的 `timestamp` 與 `quote.close` 陣列一一對應，略過 null 點
- **刪除操作**：建議使用 Supabase `delete` 搭配軟確認（confirm dialog），不加入「還原」功能
- **設計取捨**：本 US 屬 spec §4「最好有」。**核心查價、清單、輪詢、Telegram（US-01～04）不倚賴本 US**。
- **建議檔案**：
  - `components/StockChart.tsx`（面積圖元件）
  - `components/SparklineChart.tsx`（sparkline 元件）
  - 擴充 `components/WatchlistCard.tsx`（加入 sparkline 與刪除按鈕）
  - `app/api/delete-watchlist/route.ts`（刪除 API）

## Design Reference

設計稿：`docs/design.pen`「股價看板」Frame

### 本 US 涵蓋的 UI 區塊

| 區塊 | 設計圖節點 | 關鍵規格 |
|---|---|---|
| **走勢圖區域** | `chartArea` | 位於 resultCard 底部（通常介於標頭與 OHLC 列之上或依設計圖層級），高 312px，圓角 14px，`$--card` 底 + `$--border` 描邊，內距 16px |
| **時間區間 pills** | `pillRow` | 水平排列：1D · 1M · 3M · **YTD** · 1Y · 5Y。YTD 為 active 狀態（`$--secondary` 底 + 圓角 999），其餘 `$--muted-foreground` |
| **面積圖** | `chartBody` | clip 裁切，高 200px。含面積填色（green gradient）+ 線條 2.5px + AVG/最高/最低虛線 + 極值圓點（直徑 7px） |
| **圖表標記** | `hiLbl` / `loLbl` / `avgLbl` | 最高/最低價格標籤 11px，AVG 標籤 10px。`$--muted-foreground` |
| **OHLC 資訊列** | `ohlcRow` | **資料與必做驗收受 US-01 規範**；本 US 著重與設計稿一致之**樣式**（4 格網格：最高 · 最低 · 開盤 · 成交量） |
| **Sparkline** | `wl1Spark` | 卡片內小圖，高 56px，圓角 10px。面積填色（紅 gradient）+ 線條 2px，同 chartData 資料來源 |
| **刪除按鈕** | `wl1Del` | pill 圓角 999 + `$--border` 描邊，trash-2 icon +「刪除」12px，`$--muted-foreground`。點擊後觸發 confirm |

### 圖表佈局層級（與 US-01 結果卡銜接）

```
resultCard
  ├── resultHeader（US-01 股票標題 + 價格區）
  ├── chartArea (本 US)
  │    ├── chartTop（更新時間 + 時間 pills）
  │    ├── chartBody (clip, 200px)
  │    │    ├── avgP / peakP（輔助虛線）
  │    │    ├── areaFill（gradient 面積）
  │    │    ├── lineSt（區線）
  │    │    ├── hiLbl / loLbl（極值標籤）
  │    │    └── dotHi / dotLo（極值圓點）
  │    └── chartHint + chartSub（底部說明文字）
  └── ohlcRow（US-01 必做資料；本 US 可做設計稿樣式強化）
```

### 設計注意

- 時間區間 pills（1D, 1M, 3M, YTD, 1Y, 5Y）在 MVP 第一版僅為視覺元件，`1D` 有實際 chartData，其他區間可先不做切換功能
- 走勢圖上標記之極值（close 序列）與 `ohlcRow` 之 high／low（§8 第 1 點正規化）計算方式不同，兩數值可能略有差異，屬正常行為
- Sparkline 共用主圖的 chartData，不需額外 API 呼叫
- 刪除按鈕點擊後應出現軟確認（browser native `confirm()` 或自訂 dialog），避免誤刪
