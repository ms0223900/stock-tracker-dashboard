# US-05：折線圖與清單管理（最好有）

## User Story

**作為** 使用者，
**我想** 在股價結果卡看到當日走勢圖、在追蹤卡片看到 sparkline，並且可以刪除追蹤項目，
**這樣** 我能快速掌握價格趨勢並管理我的清單。

## Acceptance Criteria

- [ ] AC1：股價結果區（StockResultCard）顯示當日股價走勢**面積圖（AreaChart）**。
- [ ] AC2：走勢圖上標示當日**最高價與最低價位置**（ReferenceDot / ReferenceLine）。
- [ ] AC3：追蹤清單每張卡片（WatchlistCard）內含 sparkline 折線圖。
- [ ] AC4：每張追蹤卡片有「刪除」按鈕，點擊後出現確認提示。
- [ ] AC5：刪除確認後，該筆資料自 Supabase 移除，清單即時更新。
- [ ] AC6：刪除失敗時，畫面顯示錯誤訊息。
- [ ] AC7：圖表資料來源是 Yahoo Finance 回傳的當日 chartData，首次查詢後即有完整線圖。

## Technical Notes

- **圖表函式庫**：Recharts（`AreaChart`、`ReferenceDot`、`ReferenceLine`）
- **chartData 來源**：Yahoo Finance API 回傳的 `timestamp` 與 `quote.close` 陣列一一對應，略過 null 點
- **最高／最低價標記（走勢圖 vs OHLC 網格）**：
  - 走勢圖上的極值標記：取 chartData 序列（close 價格）的全域最大/最小及其對應時間
  - 結果卡下方的 OHLC 網格（high/low/open/close）：取 `quote.high` / `quote.low` 正規化數值（同 US-01）
  - 兩者可能因採樣粒度略有差異，屬預期行為（詳見 spec §8）
- **刪除操作**：建議使用 Supabase `delete` 搭配軟確認（confirm dialog），不加入「還原」功能
- **設計取捨**：本張 US 屬於 spec §4「最好有」範圍，不影響核心流程運作。若時間不足可延後。
- **建議檔案**：
  - `components/StockChart.tsx`（面積圖元件）
  - `components/SparklineChart.tsx`（sparkline 元件）
  - 擴充 `components/WatchlistCard.tsx`（加入 sparkline 與刪除按鈕）
  - `app/api/delete-watchlist/route.ts`（刪除 API）

## Design Reference

設計稿：`docs/design.pen`「股價看板」Frame

### 本 US 涵蓋的 UI 區塊

| 區塊 | 設計圖節點 | 關鍵規格 |
|---|---|---|
| **走勢圖區域** | `chartArea` | 位於 resultCard 底部，高 312px，圓角 14px，`$--card` 底 + `$--border` 描邊，內距 16px |
| **時間區間 pills** | `pillRow` | 水平排列：1D · 1M · 3M · **YTD** · 1Y · 5Y。YTD 為 active 狀態（`$--secondary` 底 + 圓角 999），其餘 `$--muted-foreground` |
| **面積圖** | `chartBody` | clip 裁切，高 200px。含面積填色（green gradient）+ 線條 2.5px + AVG/最高/最低虛線 + 極值圓點（直徑 7px） |
| **圖表標記** | `hiLbl` / `loLbl` / `avgLbl` | 最高/最低價格標籤 11px，AVG 標籤 10px。`$--muted-foreground` |
| **OHLC 資訊列** | `ohlcRow` | 4 格網格：最高 · 最低 · 開盤 · 成交量。每格 `$--card-muted` 底 + 圓角 14px + 內距 14px + label 12px normal + value 16px semibold |
| **Sparkline** | `wl1Spark` | 卡片內小圖，高 56px，圓角 10px。面積填色（紅 gradient）+ 線條 2px，同 chartData 資料來源 |
| **刪除按鈕** | `wl1Del` | pill 圓角 999 + `$--border` 描邊，trash-2 icon +「刪除」12px，`$--muted-foreground`。點擊後觸發 confirm |

### 圖表佈局層級

```
resultCard
  ├── resultHeader（US-01 股票標題 + 價格區）
  ├── chartArea (本 US 核心)
  │    ├── chartTop（更新時間 + 時間 pills）
  │    ├── chartBody (clip, 200px)
  │    │    ├── avgP / peakP（輔助虛線）
  │    │    ├── areaFill（gradient 面積）
  │    │    ├── lineSt（區線）
  │    │    ├── hiLbl / loLbl（極值標籤）
  │    │    └── dotHi / dotLo（極值圓點）
  │    └── chartHint + chartSub（底部說明文字）
  └── ohlcRow (4 格：最高/最低/開盤/成交量)
```

### 台股漲跌配色

設計圖變數中已定義（`_dependency-and-tech-notes.md` 有完整對照表）：

| Token | 值 | 用途 |
|---|---|---|
| `$--twse-up` | `#eb0000`（紅） | 漲 → 線條/文字為紅色 |
| `$--twse-down` | `#008a3b`（綠） | 跌 → 線條/文字為綠色 |

### 設計注意

- 時間區間 pills（1D, 1M, 3M, YTD, 1Y, 5Y）在 MVP 第一版僅為視覺元件，`1D` 有實際 chartData，其他區間可先不做切換功能
- OHLC 網格的「最高/最低」數值來自 `quote.high`/`quote.low` 正規化結果（US-01），與走勢圖上的極值（close 序列）計算方式不同，兩數值可能略有差異，屬正常行為
- Sparkline 共用主圖的 chartData，不需額外 API 呼叫
- 刪除按鈕點擊後應出現軟確認（browser native `confirm()` 或自訂 dialog），避免誤刪
