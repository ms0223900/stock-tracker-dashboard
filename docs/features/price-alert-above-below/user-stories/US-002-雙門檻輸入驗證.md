### US-002：雙門檻輸入驗證

**作為** 使用者
**我想要** 系統在儲存前驗證「以上／以下」目標價規則
**以便** 無效設定不會寫入資料庫

**輸入格式**：
- 以上目標價字串（可空）
- 以下目標價字串（可空）

**輸出格式**：
- 驗證結果與繁中錯誤訊息
- 通過時得到可寫入的數值（或 `null`）

**驗收條件**：
- [ ] 兩個皆空 → 錯誤（須至少設定一個門檻）
- [ ] 填寫的門檻須為 > 0 的有效數字（錯誤文案與既有目標價風格一致或擴充共用常數）
- [ ] 兩者皆填且以上 ≤ 以下 → 錯誤（繁中說明須以上高於以下）
- [ ] 僅填以上或僅填以下可通過
- [ ] 驗證函式集中於可重用模組（例如 `lib/validation.ts`），供表單儲存路徑呼叫

**依賴關係**：
- 無

**優先級**：P0
**相關功能**：輸入驗證／主 spec §9 儲存追蹤
