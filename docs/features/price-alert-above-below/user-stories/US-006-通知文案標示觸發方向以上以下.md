### US-006：通知文案標示觸發方向（以上／以下）

**作為** 使用者
**我想要** 收到的 Telegram／LINE 通知清楚標示是「以上」還是「以下」達標
**以便** 立刻知道觸發的是哪一種條件

**輸入格式**：
- 股票代號
- 目前股價
- 該方向目標價
- 方向（above／below）

**輸出格式**：
- 繁中通知本文含方向語意
- Telegram／LINE 共用組裝函式

**驗收條件**：
- [ ] 以上觸發之文案可辨識為「以上」或等價語意（例如漲破／達標以上）
- [ ] 以下觸發之文案可辨識為「以下」或等價語意（例如跌破／達標以下）
- [ ] 仍包含股票代號、目前股價、目標股價、觸發時間
- [ ] Telegram 與 LINE 皆使用同一組裝來源

**依賴關係**：
- 無

**優先級**：P0
**相關功能**：通知文案（`buildStockHitNotificationMessage`）／Telegram／LINE
