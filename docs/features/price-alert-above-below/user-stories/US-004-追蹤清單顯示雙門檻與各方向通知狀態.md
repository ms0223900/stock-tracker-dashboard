### US-004：追蹤清單顯示雙門檻與各方向通知狀態

**作為** 使用者
**我想要** 在追蹤清單看到每筆的以上／以下目標價與是否已通知
**以便** 確認設定與通知狀態

**輸入格式**：
- 含新欄位的 `WatchlistItem[]`（可用 fixture 或既有列驗證顯示）

**輸出格式**：
- 卡片顯示已設定的門檻
- 未設定方向不誤導
- 各方向已通知狀態可辨識

**驗收條件**：
- [ ] 有設定「以上」時顯示該目標價
- [ ] 有設定「以下」時顯示該目標價
- [ ] 未設定的方向不顯示假的 0 或誤導文案
- [ ] 以上／以下各自的已通知狀態可區分（或清楚標示哪一方向已通知）

**依賴關係**：
- US-001（必要）
- US-003 為端到端手動驗收建議（顯示邏輯可用 fixture 先驗）

**優先級**：P0
**相關功能**：追蹤清單 UI（`WatchlistCard`）
