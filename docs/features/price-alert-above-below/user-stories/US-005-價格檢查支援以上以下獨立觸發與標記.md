### US-005：價格檢查支援以上／以下獨立觸發與標記

**作為** 使用者
**我想要** 系統在檢查股價時，對「以上」與「以下」門檻分別判斷並通知
**以便** 漲破與跌破都能收到通知且互不阻擋

**輸入格式**：
- watchlist 列（含雙門檻與雙通知狀態）
- 即時／觸發用股價

**輸出格式**：
- 達標方向發送 Telegram（及選用 LINE）
- 僅該方向成功後標記對應 `is_notified`／`notified_at` 或 `is_below_notified`／`notified_at_below`
- 結果 log 區分方向

**驗收條件**：
- [ ] `target_price` 非 null 且 `price >= target_price` 且未以上通知 → 觸發以上通知流程
- [ ] `target_price_below` 非 null 且 `price <= target_price_below` 且未以下通知 → 觸發以下通知流程
- [ ] 門檻為 null 的方向不觸發、不修改該方向通知欄位
- [ ] 雙設且價格介於以下與以上之間 → 兩向皆不通知
- [ ] 一方已通知不影響另一方後續觸發
- [ ] 發送失敗時該方向標記維持 false
- [ ] 仍遵守 Telegram 成功後才標記；若有 LINE 則兩者皆成功才標記
- [ ] `/api/check-prices` 與 `/api/cron/check-prices` 共用同一檢查核心（`runWatchlistPriceCheck` 或同等）
- [ ] `last_price` 更新行為與現況一致（含 ambiguous prev-close 處理）

**依賴關係**：
- US-001、US-006

**優先級**：P0
**相關功能**：價格檢查與通知／主 spec §9／[`lib/run-watchlist-price-check.ts`](../../../../lib/run-watchlist-price-check.ts)
