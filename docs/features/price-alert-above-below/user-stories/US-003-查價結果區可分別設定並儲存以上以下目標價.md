### US-003：查價結果區可分別設定並儲存以上／以下目標價

**作為** 使用者
**我想要** 在查價結果區分別輸入「目標價以上」與「目標價以下」並儲存追蹤
**以便** 依策略設定漲破或跌破通知

**輸入格式**：
- 已查詢成功的 `StockPrice`
- 兩個目標價輸入（以上／以下）
- 通過 US-002 驗證的結果

**輸出格式**：
- Supabase insert 含對應欄位（未填門檻為 `null`）
- 清單刷新後可見新項目
- 錯誤時繁中提示

**驗收條件**：
- [ ] 以「以上／以下」兩欄取代既有單一「目標股價」輸入（不保留雙軌舊單欄）
- [ ] 儲存前呼叫 US-002 同一套驗證；失敗不 insert
- [ ] 儲存時寫入對應欄位（未填者為 null）；`is_notified`／`is_below_notified` 預設 false
- [ ] 儲存成功後清空輸入並刷新清單
- [ ] 儲存失敗顯示可讀繁中錯誤
- [ ] DB CHECK 為最後防線（即使繞過 UI 的違規寫入亦應被拒）

**依賴關係**：
- US-001、US-002

**優先級**：P0
**相關功能**：儲存追蹤 UI（`StockResultCard`／`useWatchlist`）
