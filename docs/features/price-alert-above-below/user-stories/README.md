# 到價通知以上／以下 — User Stories 一覽

本目錄對應 [`../spec.md`](../spec.md)：同一筆追蹤可分別設定「目標價以上」與「目標價以下」，並獨立觸發與標記通知。

---

## 專案／功能簡述

讓使用者對同一檔股票分別設定漲破（以上）與跌破（以下）門檻；可只設其一或兩者皆設，通知狀態互不阻擋。

---

| US | 標題 | 優先級 | 依賴 | 簡要說明 |

## 依賴說明

- **US-001**：無前置；為儲存、顯示、檢查的資料基礎。
- **US-002**：無前置；可與 US-001／US-006 平行。
- **US-003**：需欄位（US-001）與驗證（US-002）才能正確寫入。
- **US-004**：硬依賴 US-001；US-003 僅建議用於端到端手動驗收。
- **US-005**：需新欄位（US-001）與方向文案（US-006）才能完成發送整合。
- **US-006**：無前置；建議 Wave 1 先做，供 US-005 整合。
- **US-007**：依行為定案；可與實作平行，合併前對齊。

---

## 建議開發順序

| Wave | 內容 | 可否平行 |
| --- | --- | --- |
| **Wave 1** | US-001、US-002、US-006 | 三者可平行 |
| **Wave 2** | US-003、US-005 | 須待 Wave 1 對應依賴 |
| **Wave 3** | US-004 | 須待 US-001；可與 Wave 2 部分重疊 |
| **文件** | US-007 | 可穿插；功能合併前對齊主 spec |

## 非目標（本批不做）

- 編輯既有追蹤門檻、重設已通知、登入／多使用者
- 將以上／以下拆成兩筆獨立追蹤列
- 強制新增 Server Action（現況：表單驗證 + DB CHECK）
