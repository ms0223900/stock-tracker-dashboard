### US-007：更新產品規格 docs/spec.md 與功能說明

**作為** 開發者／驗收者
**我想要** `docs/spec.md`（及本功能目錄說明）反映雙門檻行為與資料欄位
**以便** 後續實作與驗收有單一真相來源

**輸入格式**：
- 本批 US 定案行為與資料模型（見 [`../spec.md`](../spec.md)）

**輸出格式**：
- 更新後的主 [`docs/spec.md`](../../../spec.md) 相關章節
- 本功能目錄 `spec.md` 與實作對齊（若實作中有微調則回寫）

**驗收條件**：
- [ ] 主 spec §7 資料模型含雙門檻與雙通知欄位說明
- [ ] §9 更新與通知改為雙向獨立規則
- [ ] §11 驗收條件涵蓋僅以上、僅以下、雙設、區間內不通知、不重複通知
- [ ] 功能目錄 `spec.md` 有欄位、觸發、遷移、非目標範圍說明

**依賴關係**：
- US-001～US-006 行為定案（文件可與實作平行，內容須與定案一致）

**優先級**：P1
**相關功能**：文件／驗收
